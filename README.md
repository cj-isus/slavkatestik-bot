# Telegram-бот с реферальными ссылками на работу

Бот с интерактивным меню: категории → предложения → кнопка с реферальной ссылкой.

## Структура файлов

| Файл | Назначение |
|---|---|
| `bot.py` | Код бота |
| `content.json` | **Весь контент**: категории, описания, ссылки |
| `config.py` | Токен и ID владельца |
| `requirements.txt` | Зависимости |

## Запуск

1. Установи зависимости (если ещё не установлены):
   ```
   pip install -r requirements.txt
   ```
2. Вставь токен от @BotFather в `config.py` (поле `BOT_TOKEN`) — либо задай
   переменную окружения `TELEGRAM_BOT_TOKEN`.
3. Запусти:
   ```
   python bot.py
   ```

## Наполнение контента

Редактируй `content.json` — перезапуск бота не нужен, просто отправь
`/reload` боту в чат.

Формат:

```json
{
  "categories": [
    {
      "id": "freelance",
      "title": "Фриланс",
      "emoji": "💼",
      "description": "Короткое описание раздела",
      "items": [
        {
          "title": "Название площадки",
          "description": "Чем интересна",
          "url": "https://ваша-реферальная-ссылка"
        }
      ]
    }
  ]
}
```

## Команды

- `/start` — главное меню
- `/help` — справка
- `/reload` — перечитать `content.json` (только для `OWNER_ID` из `config.py`)
